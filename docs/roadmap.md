# Raccoon 产品路线图

> 最后更新：2025-04-24

## 版本命名规则

自 v0.3.1 起，迭代按 **0.0.1** 递增：v0.3.1 → v0.3.2 → v0.3.3 → ...

---

## v0.3.1 — 「基础体验」：会话稳定 + 模型自由

> 目标：多会话不丢不串，模型在 Web UI 里随时换。

### 会话稳定

| # | 任务 | 说明 |
|---|------|------|
| 1 | 前端 `convId` 只读化 | 异步回调不再覆盖 `convId`，只在 `convId === null` 时赋值 |
| 2 | 前端暂停机制修复 | 暂停时真正中断流式请求（AbortController），而非仅前端挡住输入 |
| 3 | SSE 事件按会话过滤 | 每个 SSE 连接注册关注的 `conversation_id`，只推送匹配事件 |
| 4 | 会话持久化到 SQLite | `_conversations` 从内存 dict 迁移到 SQLite，重启不丢 |

### 模型自由

| # | 任务 | 说明 |
|---|------|------|
| 5 | 后端 LLM 配置 API | `GET/PUT /settings/llm`、`GET /settings/llm/presets`、`POST /settings/llm/test` |
| 6 | 配置热重载 | 保存后立即重建 LLM 客户端，无需重启服务 |
| 7 | 前端模型设置面板 | 侧边栏「设置」区域：Provider 下拉 → 自动填充 base_url → 填 Key → 选 Model → 测试 → 保存 |
| 8 | 预设模板 | 讯飞星火 / OpenAI / DeepSeek / 通义千问 / 自定义，一键切换 |
| 9 | API Key 脱敏 | 输入框 `type=password`，返回时脱敏显示 |

> 目标：用户在 Web UI 里看到 Skill 目录，搜索想要的，一键安装。

| # | 任务 | 说明 | 状态 |

## 路线图总览

```
v0.3.0 ✅ 数据获取策略层
  │
v0.3.1 ✅ 基础体验（会话稳定 + 模型自由）
  │
v0.3.2 ✅ Skill 市场
  │
v0.3.3 ✅ 定时+通知+审批
  │
v0.3.4 ✅ 工作流+记忆进化
  │
v0.3.5 📋 CDP增强+部署标准化
  │
v0.3.6 📋 场景打磨
  │
v1.0.0 🎯 正式发布
```

**核心逻辑**：先修基础体验（会话不丢 → 模型能换），再建生态（Skill 市场），再补能力（定时闭环 → 工作流 → 浏览器操控），最后打磨场景。
